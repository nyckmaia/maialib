# setup.py's install_requires intentionally keeps floors only (no upper caps), since capping
# a library there would cause resolution conflicts for anything that depends on maialib. This
# file is the opposite: an exact-pinned snapshot for *this* repository's own test/dev workflow,
# so `make tests` (and CI) behave the same today as they did when this file was verified,
# instead of silently picking up a new upstream release that happens to break something.
#
# Usage:
#   python -m venv .venv
#   # Windows: .venv\Scripts\activate ; Linux/macOS: source .venv/bin/activate
#   pip install -r requirements-dev.txt
#   make dev   # only inside a brand-new clean venv, per the project's testing workflow
#
# Verified 2026-09-16 in a clean Python 3.12.5 venv. Re-verify and update this file (with the
# date above) whenever the pinned set is deliberately refreshed.
